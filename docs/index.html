    What I learned

    Where are the data, control and management planes in your network?

    Data plane is where packets are forwarded from one host to another through switches. Control plane decides how the packets should be forwarded. Management plane is where I configure and monitor the network using CLI and Python scripts.

    How did your switches learn which port leads to each host? Use your MAC table evidence.

    My switches learn MAC addresses from incoming frames and store them in the MAC address table. They remember which port each MAC address comes from. In macs.txt, I can see the MAC addresses learned by switch s1.

    Which of the four kinds of programmability is this assignment (a network described as data, then built and documented by scripts)? Why isn't it any of the other three?

    Automated configuration management because Python scripts build the network based on topology.yaml. It doesn't change how packets are forwarded, use an external controller or program the network devices through an API.

    Week 1's 2 a.m. change on 40 switches: what would be different if those switches were described like your network?

    Configuration can be done faster because the same configuration can be applied automatically to all 40 switches. This also reduces manual work and lowers the chance of human errors.

    What's the difference between your network's data model and its serialisation? Use YAML and JSON as the example.

    Data model defines the network information while serialisation is how the data is written into a file. YAML and JSON are different formats that can represent the same network data.

    Why is it better to catch bad data in check() than with pingall? What did IPv6 notice about a duplicate address that IPv4 didn't?

    It is better to use check() because it can detect configuration errors before building the network. My check() detected duplicate IPv4 and IPv6 addresses and a link to an unknown switch. IPv6 detected the duplicate address and showed dadfailed, while IPv4 accepted the duplicate address without the same warning.

    What does your Git history give you that copying files into folders named topology-v2-final wouldn't?

    Git records the history of changes made to my project. I can review, compare different versions and restore an older version if something goes wrong. It is easier to manage.
